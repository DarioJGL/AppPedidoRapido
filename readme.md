# PedidoRapido 🚀

**Gestor de pedidos para negocios locales**  
*Proyecto Final — Materia: Gestión de Proyectos*

## 📋 Descripción General
PedidoRapido es una aplicación web ligera orientada a pequeños negocios informales o de barrio (restaurantes, ferreterías, papelerías) que necesitan digitalizar el registro de sus pedidos del día. 

Este proyecto fue desarrollado bajo el marco de trabajo **Scrum** a lo largo de 2 semanas (2 Sprints) utilizando asistentes de **Inteligencia Artificial** de última generación para optimizar el ciclo de vida del software[cite: 1].

## 🛠️ Arquitectura y Tecnologías
La aplicación se ejecuta completamente en el cliente (navegador web), eliminando las barreras de servidores o configuraciones complejas[cite: 1]:
*   **HTML5 & CSS3:** Interfaz de usuario limpia, intuitiva y completamente accesible.
*   **JavaScript (Vanilla):** Lógica del negocio y manipulación dinámica del DOM[cite: 1].
*   **Web Storage API (`LocalStorage`):** Persistencia de datos local para almacenar y consultar el historial sin necesidad de bases de datos tradicionales[cite: 1].

## 🤖 Kit de Herramientas de IA Utilizadas
En cumplimiento con los requerimientos de la materia, implementamos y auditamos el uso de las siguientes herramientas en sus respectivas fases[cite: 1]:

1.  **Google Stitch & v0 by Vercel:** Utilizados en la fase de diseño para la generación y maquetación de los componentes de la interfaz de usuario (tarjetas de pedidos, formularios y tablas de resumen)[cite: 1].
2.  **OpenCode & GitHub Copilot:** Empleados de forma diaria como asistentes interactivos en la terminal y el editor para agilizar la codificación de la lógica en JavaScript y localStorage[cite: 1].
3.  **Claude Code:** Utilizado al cierre del Sprint 2 para la auditoría completa del repositorio, la refactorización de funciones críticas y el armado del entorno técnico[cite: 1].
4.  **ChatGPT / Claude (Conversacional):** Herramientas clave del Product Owner y Scrum Master para la redacción de Historias de Usuario, definición de Criterios de Aceptación y estructuración de actas de retrospectiva[cite: 1].
